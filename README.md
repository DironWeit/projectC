#### В файле logic.c
```c

int my_getch() {
// Скопирую старые настройки терминала и скажу, что будут использоваться новые
struct termios oldt, newt;
// создал переменную для символа
int ch;
// получаю текущие настройки STDIN_FILENO - стандартный ввод (обычно клавиатура)
tcgetattr(STDIN_FILENO, &oldt);
// копирую старые настройки в новые
newt = oldt;
// меняю флаги в настройке (подробней в сноске #1)
newt.c_lflag &= ~(ICANON | ECHO);
// применяю новые настройки
tcsetattr(STDIN_FILENO, TCSANOW, &newt);
// Читаю символ
ch = getchar();
// Возвращаю старые настройки
tcsetattr(STDIN_FILENO, TCSANOW, &oldt);
// возвращаю символ
return ch;
}

```

Сноска №1:
Разберем эту строку: ```newt.c_lflag &= ~(ICANON | ECHO);```  
c_lflag - локальные флаги  
| Режим | Флаг | Обычное состояние (ВКЛ) | Наше состояние (ВЫКЛ) |
|-------|------|------------------------|----------------------|
| **Канонический режим** | `ICANON` | Терминал буферизирует ввод, отправляет программе только после нажатия Enter | Каждый символ сразу поступает в программу |
| **Эхо** | `ECHO` | Нажатые клавиши отображаются на экране | Символы НЕ показываются на экране |

Операция &= ~:  
~ - побитовое НЕ (инвертирует биты)  
&= - побитовое И с присваиванием

    window,  // окно
    -1; // любой драйвер

}
