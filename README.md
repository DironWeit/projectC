1)  Установлю библиотеку CSFML командой  sudo apt-get install libcsfml-dev 

2) Создам файл main.c

3)  Создадам двумерный массив 4x4

4) создам файлы logic.c и logic.h в папке logic

5) Функция обнуления массива и вывода

6) в основной папке создам и настрою Makefile для запуска и билда приложения


**Работа с приложением**

1) Сначала очистить все временные файлы командой в терминале: make delet

// rm -f main.o logic.o game2048

2) Забилдить проект командой: make

// gcc -c logic/logic.c

3) Запустить проект командой: make run

// gcc -c main.c

// gcc -o game2048 main.o logic.o
